Live Pipeline Execution Flow

Event-driven state transitions across 5 microservices

1. Application Service (:8081)

Validates applicant, saves application state SUBMITTED, emits ApplicationSubmittedEvent to Kafka.

2. Credit Scoring Service (:8082)

Computes score via Credit Bureau Client (protected by Resilience4j Circuit Breaker), emits CreditScoredEvent.

3. Underwriting Service (:8083)

Rule Engine evaluates risk tier (Auto-Approve ≥700, Auto-Reject <550, Manual Review 550-699), emits UnderwritingDecidedEvent.

4. Disbursement Service (:8084)

Executes fund transfer with Idempotency-Key constraint, emits DisbursedEvent.

5. Notification Service (:8085)

Consumes pipeline events and dispatches Email/SMS notifications to applicant.
